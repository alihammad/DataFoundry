# DataFoundry CLI

`datafoundry` command-line client for the DataFoundry control plane (validate, deploy, status, export, destroy).

Part of the DataFoundry monorepo — see `specs/001-one-click-platform-deployment/` for design artifacts.

## Development

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
datafoundry --help
```
